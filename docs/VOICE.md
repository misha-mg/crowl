# Голосовые сообщения Crowl

Crowl принимает Telegram voice, скачивает OGG/Opus, преобразует его через FFmpeg в mono WAV 16 kHz и запускает локальный whisper.cpp. Расшифровка затем поступает в ту сессию, которой принадлежит исходное сообщение, без отдельной публикации в чате. Распознавание и прогресс агента обновляют одно обычное сообщение, затем оно заменяется итогом; Telegram Reply к заданию не используется. Во время работы обновляется статус «печатает». Ошибочное или пустое распознавание не должно запускать агента.

## Подготовка Mac Mini

```bash
cd /path/to/project/.crowl
npm run voice:setup
npm run doctor
```

Подготовка устанавливает только отсутствующие формулы Homebrew `ffmpeg` и `whisper-cpp`. Если инструменты уже установлены вручную и доступны, Homebrew не требуется. Для ручных установок используются абсолютные `FFMPEG_BIN`, `WHISPER_BIN`, `WHISPER_MODEL_PATH` в `.env`.

По умолчанию используется общая многоязычная модель `base` в `~/Library/Caches/crowl/ggml-base.bin`. Она занимает около 142 MiB и подходит для русского языка; `.en` модели предназначены только для английского. Модель не копируется в каждый проект. Эти характеристики и опубликованная контрольная сумма приведены в [официальном списке моделей whisper.cpp](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md).

Обычный запуск Crowl не устанавливает инструменты и не скачивает модель. `voice:setup` — явная команда подготовки. Установщик проверяет, что FFmpeg поддерживает Opus, PCM, OGG и WAV, а не просто запускается: например, FFmpeg из браузерных тестов может поддерживать только видео. Затем проверяется запуск `whisper-cli`.

Модель скачивается во временный файл с лимитом 256 MiB и таймаутом 10 минут. Проверяются размер, опубликованный SHA1 `465707469ff3a37a2b9b8d8f89f2f99de7299dac` и заголовок GGML; только после этого файл атомарно становится рабочей моделью. Ошибка не заменяет существующую модель частичной загрузкой. Параллельные установщики одной модели защищены SQLite-блокировкой, которая освобождается ОС после сбоя.

Для уже существующей пользовательской модели проверяется формат GGML. Для стандартного имени `ggml-base.bin` также проверяется контрольная сумма. Повреждённый существующий файл не удаляется скрыто: команда сообщает, как исправить путь или повторить установку.

## Работа с несколькими сессиями

На один экземпляр Crowl одновременно работает одна цепочка STT. Голосовые из разных сессий проходят через отменяемую FIFO-очередь, а текстовые задачи других сессий могут продолжаться. Отмена ожидающего голоса не занимает слот Whisper и не блокирует следующие сообщения.

Остановка активного распознавания завершает его процесс перед удалением временных файлов. После отмены слот STT освобождается. Аудио удаляется после успешного распознавания, ошибки и отмены; файлы после аварийного завершения очищаются при следующем запуске экземпляра.

Ограничения: 5 минут и 20 MB на голосовое; по 5 минут на преобразование и распознавание; максимум 64 KiB результата. Настройки `-nf` и `-sns` уменьшают лишние повторения/несловесные токены, но не гарантируют отсутствие ошибок модели. Автоматическое определение языка используется для смешанной русской и технической английской речи. [Параметры whisper-cli](https://github.com/ggml-org/whisper.cpp/blob/master/examples/cli/README.md)

## Приёмка настоящего аудио

После успешного `voice:setup` отправьте боту короткое русское голосовое, например: «Создай тестовый файл voice-test.txt с текстом API ready». Проверьте статус «печатает», смену распознавания на прогресс и итог в одном сообщении, результат в нужной сессии и файл в проекте. Отдельной расшифровки и Reply к голосовому быть не должно. Затем отправьте два голоса в разные сессии, отмените один во время обработки и убедитесь, что второй выполнился.

Отдельно проверьте голос после запуска через LaunchAgent: он должен использовать те же абсолютные пути к инструментам и общую модель, что и foreground-запуск.

## Что проверено при реализации

Проверены исполняемые тестовые процессы преобразования/распознавания, аргументы с путями с пробелами, русский результат, пустой результат, лимиты, очистка, сериализация, отмена ожидающего и активного голоса, атомарная загрузка и проверка контрольной суммы. Это проверки программного конвейера, не оценка качества настоящего Whisper.

В текущей ограниченной среде разработки нет whisper-cli и модели. Запрос к Hugging Face из shell завершился `Could not resolve host`; найденные приватные Playwright FFmpeg-сборки не имеют аудиоформатов/Opus. Поэтому настоящее распознавание не подтверждено. Установка в системный Homebrew и пользовательский cache за пределами разрешённых путей не выполнялась.
