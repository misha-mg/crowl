## Что покрывают тесты

- Сессии Codex и Claude Code: создание, переключение, переименование, закрытие и продолжение по сохранённому native ID.
- Настоящие дочерние процессы с тестовыми агентами: JSON-обмен через stdin/stdout, Unicode, ошибки протокола, таймауты и остановка дерева процессов.
- Очередь и лимит выполнения: последовательная работа по умолчанию, явная параллельность, отдельные очереди и паузы сессий.
- Проверка владельца Telegram-чата, адресация Reply, вопросы агенту, разрешения и устаревшие callback-кнопки.
- Доставка: повторные попытки, Telegram rate limits, редактирование прогресса, длинные ответы, восстановление после сбоя и отсутствие повторного запуска задачи при повторной отправке результата.
- Представление: одно сообщение для голосового ввода, прогресса и результата; heartbeat «печатает»; доступные публичные сводки reasoning.
- SQLite: миграции, резервное копирование, индексы, дедупликация и очистка технических записей с сохранением сессий и результатов.
- Установка в независимые проекты, пути с пробелами, запуск из другой директории, исключение секретов и отказ от перезаписи существующей `.crowl`.
- Голосовой конвейер с тестовыми FFmpeg/Whisper, лимиты, отмена, очистка аудио и проверка загружаемой модели.
- Настройки и lifecycle LaunchAgent с тестовым runner.

Автотесты используют временные проекты, тестовые процессы и имитацию Telegram API. Им не нужны реальные Telegram-токены, аккаунты моделей или доступ к рабочей истории. Они проверяют поведение Crowl, но не подтверждают доступность конкретного аккаунта, совместимость установленного CLI или качество распознавания живого аудио.

## Локальная диагностика

Из настроенного экземпляра `<проект>/.crowl`:

```bash
npm run app:version
npm run doctor
npm run probe
```

`app:version` показывает версию и fingerprint исходников. `doctor` проверяет окружение, а `probe` — доступность протоколов CLI без отправки задачи модели. Сравнивайте fingerprint при обновлении установленной копии.

Полный ход модели проверяется отдельно:

```bash
npm run smoke -- codex
npm run smoke -- claude
```

Smoke-проверки создают временный проект, проверяют изменение файла и продолжение контекста. Они используют локально авторизованный аккаунт и могут расходовать его лимит. При подготовке публикации 29 октября эти проверки не запускались.

## Ручная приёмка установленного экземпляра

1. Проверить `doctor` и `probe` для выбранного агента.
2. В Telegram создать сессию, отправить задачу на изменение тестового файла и продолжить разговор с сохранённым контекстом.
3. Перезапустить Crowl и продолжить ту же сессию.
4. Проверить Ask, подтверждение и отказ, вопрос через Reply и остановку текущей задачи.
5. Отправить несколько задач, проверить очередь и явное продолжение после остановки.
6. При настроенном голосе отправить русское аудио с техническими терминами и оценить результат распознавания.
7. Проверить фоновую работу после установки LaunchAgent и нового login пользователя.
8. Для нескольких проектов проверить разные директории, ботов и независимую историю.

Публикация исходников не обновляет работающую `.crowl`. Инструкции по установке, backup и обновлению: [README](README.md), [сервис](docs/SERVICE.md), [голос](docs/VOICE.md), [несколько проектов](docs/PROJECTS.md).
